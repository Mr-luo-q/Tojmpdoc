# make-speed-test-zip.py 中文说明

职责：把 2026-10-14 这次「手机小模型提速」实测的相关文档、脚本、原始数据打成一个 zip，包内按主题分六类，并自动生成 `说明.txt` 与 `清单.tsv`。

输入：`<项目目录> <输出zip>`。两个参数都有默认值，直接运行会把当前目录打包成 `手机提速实测包-20261014.zip`。

输出：一个 zip，含说明、清单与六类内容。

```text
说明.txt                 结论与关键数字速查 + 每份文档回答什么问题 + 条件与局限
清单.tsv                 归档内路径、字节数、SHA-256，用于校验包内文件未被改动
01-实验设计/             调研与复现（方法、路线取舍、验收门槛）+ 操作手册
02-实测结果/             结果正文 + 各 suite 对照表 + 原始数据/（逐调用 TSV 与原始 JSON）
03-工具/                 八个脚本，每个配同名中文说明；含 termux-run.sh 入口包装器
04-提示词/               题集、对话题、缓存长短前缀与用法说明
05-证据与来源/           来源索引、验证记录、验证日志、sources/ 一手资料原文
06-历史基线/             本次对照所依据的上一轮报告
```

与仓库其他打包脚本的分工：

| 脚本 | 定位 |
|---|---|
| `make-docs-zip.py` | 完整文档包，全部脚本与说明书 |
| `make-research-zip.py` | GPU/NPU 调研包 |
| `make-k70e-zip.py` | K70E 部署包 |
| `make-speed-test-zip.py` | 本轮提速实验包：设计 + 结果 + 工具 + 原始数据 + 证据 |

实现要点沿用 `make-research-zip.py`：手工构造 `ZipInfo` 并设置 UTF-8 文件名标志位（bit 11）与 Unix 权限位（左移 16 位），中文名在各平台都不会乱码，`.sh`/`.py` 解压后自带可执行权限。新增一处：打包后立刻读回做 `testzip()` CRC 全量校验，并把条目数与总体积打印出来。

```powershell
python tools/make-speed-test-zip.py . 手机提速实测包-20261014.zip
```

读取：项目目录下的文档、脚本、`research/speed-20261014/`、`phone-prompts/`。写入：输出 zip。不负责：核对文档内容与实测数据是否一致（那要靠 `06-历史基线/` 与 `02-实测结果/原始数据/` 互查）；也不包含 K70E 部署包与 GPU/NPU 调研包里的内容，那些在各自专门的包里。

清单缺失项不会中断打包，只在最后打印，便于发现改名导致的漏收。
