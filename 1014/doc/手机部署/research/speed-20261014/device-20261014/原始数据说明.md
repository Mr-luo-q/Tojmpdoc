## 三个没有保留的文件，以及原因

采集过程中产生过三份不含信息的文件，已从本目录移除，在此说明避免以后被误当成漏采。

```text
thermal-types.txt / thermal-temps.txt    各 0 字节
    尝试批量读取 68 个热区的类型与温度，全部 Permission denied
    （连 adb shell 身份也一样），通配符没匹配到可读文件，只留下空文件。

server-cmdline.bin                       52 字节，内容是 No such file or directory
    想留存测量前那个 llama-server 的启动参数，但抓取时进程已被停止，
    /proc/<pid>/cmdline 已经不存在。
```

热区不可读本身是有效证据，完整保留在 `env-snapshot.log` 第 8 段。

```text
ls: cannot open directory '/sys/class/thermal': Permission denied
ls: cannot open directory '/sys/class/power_supply': Permission denied
```

因此本轮温度只能用 `dumpsys battery` 的电池值加频率采样间接约束，这是结果文档写明的主要测量局限。测量前那个服务的参数为 1.5B、`-t 4 -c 4096`、监听 8080，记录在结果正文的测试条件一节。
