# 手机测评（端侧可行性）

> 建立时间：2026-10-13
> 定位：`D:\项目\手机部署` 的**测评侧**工作目录。部署侧的原产物（Termux、llama.cpp 编译、
> 硬件探测、速率表）留在原项目里，不在本目录复制。
> 依据源文件：`D:\项目\手机部署\Token速率详表.md`、`CPU性能实测报告.md`、
> `bench-server.doc.md`、`bench-server.ps1`；负载画像取自
> `D:\项目\autodl-tmp\new_demo\runs\quota200_20261004_v2\`。

## 这个目录干什么

把合成轨迹的真实 token 画像搬到手机端模型上量时延与可行性，产出三个数：

```text
单轮要等多久          一条轨迹跑多久        前缀缓存能省多少
```

## 边界

`D:\项目\手机部署\**` 与 `D:\项目\autodl-tmp\**` 都当只读，不在那边改文件。
本目录只放我们自己新写的方案、脚本、实测记录与产物；原始响应和日志进 `logs\`
（已被 `_work\.gitignore` 排除，不入库）。

## 命名与验证状态约定

文件名沿用仓库习惯，用 `NN_主题.md` 编号；每个脚本配同名中文 `.md`。
结论按三档标注，不混用：

```text
已核对   有源文件、实测日志或现场复算支撑
推算     由已实测速率外推，写清假设
待确认   需要手机连线，或需要额外工具才能落地
```
