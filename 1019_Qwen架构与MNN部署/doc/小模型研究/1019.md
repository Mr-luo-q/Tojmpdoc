## 2. GQA：分组查询注意力

### 2.1 解决的问题

标准多头注意力（MHA）中，Q 头数与 KV 头数强制绑定。16 个 Q 头就要存 16 组 K/V，KV Cache 很大。GQA 让**多个 Q 头共享一组 K/V 头**。

Qwen3-0.6B 的配置是 **16 个 Q 头共享 8 个 KV 头**，即每 2 个 Q 头共用 1 个 KV 头。

### 2.2 单 token 的真实形状

一个 token 的隐藏状态是 `(1024,)`，经过三个线性投影：

| 项目 | 头数 | 每头维度 | 单 token 形状 | 总特征维度 |
| ---- | ---: | -------: | ------------- | ---------: |
| Q    |   16 |      128 | `(16, 128)`   |       2048 |
| K    |    8 |      128 | `(8, 128)`    |       1024 |
| V    |    8 |      128 | `(8, 128)`    |       1024 |

**关键校正**：不是"一个 token 生成一个 Q、K、V 向量"，而是生成**一组** Q 头向量（16 个）、**一组** K 头向量（8 个）、**一组** V 头向量（8 个）。

### 2.3 共享关系

第 `h` 个 Q 头对应的 KV 头为：

```text
g = h // 2
```

- Q 头 0、1 → KV 头 0
- Q 头 2、3 → KV 头 1
- …
- Q 头 14、15 → KV 头 7

**共享发生在头维度，不在 token 维度**：每个 token 仍然有自己的 8 个 K 头和 8 个 V 头；跨 token 的注意力仍然逐 token 计算。

### 2.4 前向与解码时的形状

**Prefill / 训练阶段**：

```text
Q: (bs, seq, 16, 128)
K: (bs, seq, 8, 128)
V: (bs, seq, 8, 128)
```

计算时第 `h` 个 Q 头使用第 `h//2` 个 KV 头，得到 `(bs, 16, seq, seq)` 的分数。

**Decode 阶段生成一个新 token**：

```text
Q_new: (bs, 16, 128)
K_new: (bs, 8, 128)
V_new: (bs, 8, 128)
```

追加到 KV Cache：

```text
K_cache: (bs, 8, past_len+1, 128)
V_cache: (bs, 8, past_len+1, 128)
```

**Cache 里存 8 个头，不是 16 个**；复制/广播只发生在计算时。

### 2.5 GQA 的好处：不止省显存

- **缓解内存带宽瓶颈**：decode 时每生成一个 token 需加载全部历史 KV，GQA 直接减少搬运量，加速解码。
- **减少参数量与部分计算**：K/V 投影矩阵随 KV 头数缩小。
- **性能损失极小**：T5-XXL 实验显示 GQA 相比 MHA 质量差距 < 0.5%，吞吐提升约 2 倍；Qwen3-0.6B 的 2:1 压缩比效果几乎无损。

GQA 是一个可调的"效率-质量"旋钮：组数 \( g \) 越大越接近 MHA（质量高、效率低），\( g=1 \) 即 MQA（效率极致、质量下降）。

## 3. QK-Norm：注意力内部的稳定器

### 3.1 是什么

QK-Norm 是**训练稳定化技术**，不是效率技巧。它在注意力机制**内部**，对投影后的 **Q 和 K** 分别施加 **RMSNorm**，位置在 **RoPE 之前**。

### 3.2 具体实现

- **逐头进行**：对每个头的 `head_dim = 128` 维独立归一化，而非整个投影向量。
- **使用 RMSNorm**：两个独立的 `RMSNorm(head_dim, eps=1e-6)`。
- **只作用于 Q 和 K，V 不参与**。

```python
query_states = self.q_norm(self.q_proj(hidden_states).view(...))
key_states   = self.k_norm(self.k_proj(hidden_states).view(...))
value_states = self.v_proj(hidden_states).view(...)   # 无 norm
```

### 3.3 "在 RoPE 之前"的含义

RoPE 不是只在第一层之前应用一次，而是**每一层的注意力模块内部**都对 Q、K 做旋转。单层内的顺序为：

```text
投影 → QK-Norm → RoPE → 注意力计算
```

"在 RoPE 之前"指 QK-Norm 发生在 RoPE 旋转之前。（注：不同框架实现可能有差异，需以具体代码为准。）

### 3.4 目的

约束 \( Q \cdot K^\top \) 点积的数值范围，防止 softmax 饱和，减少训练损失尖峰。

## 4. RMSNorm 与 LayerNorm 的区别

### 4.1 数学定义

设 \( x \in \mathbb{R}^d \)，可学习缩放 \( \gamma \)，偏置 \( \beta \)。

**LayerNorm**：

\[
\mu = \frac{1}{d}\sum_i x_i,\quad \sigma = \sqrt{\frac{1}{d}\sum_i (x_i-\mu)^2 + \epsilon}
\]
\[
\text{LN}(x) = \frac{x-\mu}{\sigma} \odot \gamma + \beta
\]

**RMSNorm**：

\[
\text{RMS}(x) = \sqrt{\frac{1}{d}\sum_i x_i^2 + \epsilon},\quad
\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \odot \gamma
\]

### 4.2 核心差异对照

| 维度                   | LayerNorm           | RMSNorm        |
| ---------------------- | ------------------- | -------------- |
| 是否减均值             | 是                  | **否**         |
| 分母                   | 标准差 \( \sigma \) | 均方根 RMS     |
| 是否含偏置 \( \beta \) | 通常有              | 通常没有       |
| 统计量计算             | 两遍（均值+方差）   | 一遍（平方和） |
| 输出均值               | 强制为 0            | 不约束         |
| 平移不变性             | **是**              | **否**         |
| 尺度不变性             | 是                  | 是             |

### 4.3 为什么大模型偏好 RMSNorm

1. **计算更省**：一遍统计 vs 两遍。
2. **保留均值信息**：均值可能携带有效信号，强行中心化未必有益。
3. **数值更稳定**：绕开 \( x-\mu \) 在小方差时的数值扰动。
4. **与残差结构配合更好**：不反复"重置"残差流的均值偏移。

### 4.4 Qwen3-0.6B 中的归一化分布

- **全部使用 RMSNorm，无 LayerNorm**。
- 每层有两处骨架 RMSNorm：`input_layernorm`（注意力前）、`post_attention_layernorm`（FFN 前）。
- 模型末尾有 `final_norm`。
- 注意力内部另有 QK-Norm（仅 Q、K）。

## 5. 为什么要做尺度归一

尺度失控会从三方面破坏模型：softmax 饱和导致梯度消失、fp16 溢出、多层残差累积发散。

### 5.1 注意力分数爆炸

设 `head_dim = 128`，Q/K 分量标准差为 \( \sigma \)。点积标准差为：

\[
\text{std}(q\cdot k) = \sqrt{128}\,\sigma^2 \approx 11.3\,\sigma^2
\]

缩放后分数标准差 = \( \sigma^2 \)。

| \( \sigma \) | 点积 std（未缩放） | 缩放后分数 std | 后果                   |
| -----------: | -----------------: | -------------: | ---------------------- |
|            1 |               11.3 |          **1** | 正常                   |
|            3 |                102 |              9 | 开始尖锐               |
|            5 |                283 |             25 | 严重饱和               |
|           10 |               1131 |            100 | 完全 one-hot，梯度归零 |

### 5.2 softmax 饱和与梯度消失

设 10 个 logits，最大项 softmax 输出：

| logits 尺度 | 最大项 softmax | 梯度状态         |
| ----------- | -------------: | ---------------- |
| std ≈ 1     |           0.15 | 梯度充足         |
| std ≈ 9     |           0.99 | 接近 one-hot     |
| std ≈ 25    |           ≈1.0 | 完全饱和，梯度≈0 |

softmax 梯度 \( \partial p_i/\partial z_j = p_i(\delta_{ij}-p_j) \)。当 \( p_{\max}\to 1 \)、其余 \( \to 0 \) 时，所有梯度趋近 0，注意力头无法学习。

### 5.3 fp16 溢出

fp16 最大值约 **65504**。点积极端值约 \( 56\sigma^2 \)：

| \( \sigma \) | 点积极端值 | 状态                 |
| -----------: | ---------: | -------------------- |
|           20 |      22400 | 接近危险             |
|           30 |      50400 | 极危险               |
|       **35** |  **68600** | **溢出 → inf → NaN** |

### 5.4 多层残差累积

假设每层放大 \( r \) 倍，28 层后：

| \( r \) | \( r^{28} \) |
| ------: | -----------: |
|    1.05 |          3.9 |
|    1.10 |         14.4 |
|    1.20 |          164 |
|    1.50 |        36000 |

Pre-Norm 把每层输入尺度钉住，防止指数累积。

## 6. 除以均方根的数值含义

### 6.1 核心恒等式

\[
\text{RMS}(y) = 1,\quad \|y\|_2 = \sqrt{d}
\]

无论输入是什么，RMSNorm 输出模长恒为 \( \sqrt{d} \)。

### 6.2 方向不变

所有分量乘同一正标量 \( 1/\text{RMS}(x) \)，比值不变、方向不变，只是**径向缩放到半径 \( \sqrt{d} \) 的球面**。

### 6.3 RMS 与标准差、均值的关系

\[
\boxed{\text{RMS}^2 = \mu^2 + \sigma^2}
\]

推论：

- \( \text{RMS} \ge \sigma \)，等号当且仅当 \( \mu = 0 \)；
- 均值非零时 RMSNorm 分母更大，缩放更"保守"。

### 6.4 具体算例

取 \( x = [3, -1, 4, 1] \)，\( d = 4 \)：

- 均值 \( \mu = 1.75 \)
- 平方和 = 27
- \( \text{RMS} = \sqrt{6.75} \approx 2.598 \)
- 方差 \( \sigma^2 = 6.75 - 3.0625 = 3.6875 \)，\( \sigma \approx 1.920 \)

验证：\( 1.75^2 + 1.920^2 = 6.75 \) ✓

**RMSNorm 输出**：

\[
y = [1.155,\ -0.385,\ 1.540,\ 0.385]
\]

| 统计量   | RMSNorm | LayerNorm |
| -------- | ------: | --------: |
| 输出均值 |   0.674 |     **0** |
| 输出方差 |   0.546 |     **1** |
| 输出 RMS |   **1** |         1 |
| 输出模长 |       2 |         2 |

两者模长都是 \( \sqrt{d}=2 \)，但落点不同：LayerNorm 落在"均值=0"的超平面与球面交线；RMSNorm 落在整个球面。

### 6.5 几何图像

|          | LayerNorm                         | RMSNorm               |
| -------- | --------------------------------- | --------------------- |
| 输出约束 | 均值=0 **且** 模长=\( \sqrt{d} \) | 仅模长=\( \sqrt{d} \) |
| 落点集合 | 球面 ∩ 超平面                     | 整个球面              |

## 7. 为什么 V 不需要 QK-Norm

### 7.1 V 只被加权，不参与打分

\[
a = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right),\quad \text{out} = aV
\]

- Q、K 决定"看哪里"（进入 softmax）；
- V 决定"看到什么"（只被线性加权）。

### 7.2 尺度传递性质不同

**V 放大 \( c \) 倍 → 输出精确放大 \( c \) 倍**，权重不变。

**Q·K 放大 \( c \) 倍 → softmax 被非线性扭曲**：

| logits            | softmax                        |
| ----------------- | ------------------------------ |
| \( [1, 0.5, 0] \) | \( [0.506, 0.307, 0.186] \)    |
| \( [10, 5, 0] \)  | \( [0.993, 0.0067, 0.00005] \) |

### 7.3 V 的幅度本身携带语义

V 是"内容向量"，不同 token 的幅度差异有意义。归一化 V 会把强信号和弱信号拉平：

- 不归一化：\( 0.5[10,0] + 0.5[1,0] = [5.5, 0] \)，强信号主导；
- 归一化后：两者都变成 \( [\sqrt{2}, 0] \)，差异被抹平。

### 7.4 风险量级对比

|                | Q·K 点积                           | V                |
| -------------- | ---------------------------------- | ---------------- |
| 跨维累积       | 128 维求和，std × \( \sqrt{128} \) | 无               |
| 非线性环节     | softmax（指数）                    | 无               |
| 溢出路径       | exp 前就可能 inf                   | 线性放大，有兜底 |
| 幅度是否有语义 | 无                                 | **有**           |

### 7.5 V 的尺度由谁兜底

1. `input_layernorm`：投影前隐藏状态已归一化；
2. 输出投影 \( W_o \)：可学习补偿；
3. 残差 + `post_attention_layernorm`：重新控制尺度；
4. 梯度信号：异常时自然拉回。

QK-Norm 必要，是因为 Q·K 的问题发生在 softmax **内部**，饱和后梯度死亡、后续层无法补救；V 的问题发生在 softmax **之后**，线性可补救。

## 8. SwiGLU：门控 FFN

### 8.1 FFN 的角色

FFN 对每个 token **独立**做变换，不混合 token。标准 FFN 是"升维 → 激活 → 降维"：

\[
y = W_2 \cdot \text{ReLU}(W_1 x)
\]

ReLU 对每个维度独立、固定规则地"正保留、负归零"，**无法根据输入动态决定开关**。

### 8.2 门控思想

用一条路径算"开关"，另一条路径算"内容"，逐元素相乘：

```text
x → W_gate → g  （开关）
x → W_up   → u  （内容）
输出 = g ⊗ u
```

开关 \( g \) 可以是任意实数：0 关闭、1 原样、>1 放大、<0 反向抑制。

### 8.3 GLU 与 SwiGLU

**GLU**：

\[
\text{GLU}(x) = \sigma(W_{\text{gate}}x) \otimes (W_{\text{up}}x)
\]

**SwiGLU**：把 sigmoid 换成 Swish：

\[
\boxed{\text{SwiGLU}(x) = \text{Swish}(W_{\text{gate}}x) \otimes (W_{\text{up}}x)}
\]

\[
\text{FFN}(x) = \text{SwiGLU}(x)\cdot W_{\text{down}}
\]

其中 \( \text{Swish}(z) = z\cdot\sigma(z) \)。

### 8.4 Swish vs sigmoid 数值对比

| \( z \) | \( \sigma(z) \) | \( \text{Swish}(z) \) |
| ------: | --------------: | --------------------: |
|    -3.0 |           0.047 |            **-0.142** |
|   -1.28 |           0.218 |    **-0.279**（最小） |
|       0 |           0.500 |                     0 |
|     2.0 |           0.881 |                 1.762 |
|     5.0 |           0.993 |                 4.966 |

**关键差异**：

1. sigmoid 恒正，只能"关小"；Swish 可为负，能**反向抑制**。
2. sigmoid 会饱和（梯度→0）；Swish 对正输入**不饱和**。

### 8.5 Qwen3-0.6B 的形状

| 矩阵                  | 形状         | 参数量 |
| --------------------- | ------------ | -----: |
| \( W_{\text{gate}} \) | (1024, 3072) | 3.145M |
| \( W_{\text{up}} \)   | (1024, 3072) | 3.145M |
| \( W_{\text{down}} \) | (3072, 1024) | 3.145M |

```text
h:        (bs, seq, 1024)
gate:     h @ W_gate → (bs, seq, 3072)
up:       h @ W_up   → (bs, seq, 3072)
activated = Swish(gate) ⊗ up → (bs, seq, 3072)
out:      activated @ W_down → (bs, seq, 1024)
```

每层参数量 \( 3 \times 1024 \times 3072 = 9.44\text{M} \)，28 层合计约 264M，FP16 约 **528 MB**。

### 8.6 手算例子

设 \( W_{\text{gate}}x = [1.5, -2.0, 0.3] \)，\( W_{\text{up}}x = [4.0, 3.0, -1.0] \)。

**开关信号**：

```text
Swish(1.5)  = 1.5 × 0.818  =  1.227
Swish(-2.0) = -2.0 × 0.119 = -0.238
Swish(0.3)  = 0.3 × 0.574  =  0.172
```

**逐元素相乘**：

```text
维度 0:  1.227 × 4.0   =  4.908   （放大）
维度 1: -0.238 × 3.0   = -0.714   （反向抑制）
维度 2:  0.172 × (-1.0)= -0.172   （小幅通过）
```

对比 ReLU（对 \( [4.0, 3.0, -1.0] \)）：`[4.0, 3.0, 0.0]`。

| 维度 |                 SwiGLU |        ReLU |
| ---- | ---------------------: | ----------: |
| 0    |      **4.908**（放大） |         4.0 |
| 1    |     **-0.714**（抑制） | 3.0（原样） |
| 2    | **-0.172**（小幅通过） |         0.0 |

**ReLU 只能"保留或归零"；SwiGLU 能"放大、原样、缩小、反向抑制"，且由输入动态决定。**

### 8.7 为什么中间维度是 3072

标准 FFN：2 矩阵 × 4096 维 = 8.39M/层。

SwiGLU 若用 4096：3 矩阵 × 4096 = 12.58M（多 50%）。

为同等参数预算，缩到 \( \frac{2}{3}\times 4096 \approx 2731 \)，取整 **3072**：

\[
3 \times 1024 \times 3072 = 9.44\text{M}
\]

用"多一个矩阵"换"门控表达力"，同时缩窄宽度控制参数总量。

## 9. KV Cache 与 FFN 参数的内存对比

### 9.1 性质差异

|                 | FFN 参数       | KV Cache         |
| --------------- | -------------- | ---------------- |
| 性质            | 模型权重，静态 | 运行时激活，动态 |
| 随 batch 增长   | 否             | **是**           |
| 随 seq_len 增长 | 否             | **是**           |
| 生命周期        | 常驻           | 每请求分配释放   |

### 9.2 Qwen3-0.6B 的数字

**FFN 参数（FP16）**：28 层 × 9.44M ≈ 264M 参数 → **约 528 MB**。

**KV Cache（FP16）**：

- 每 token 每层：\( 2 \times 8 \times 128 \times 2\text{ B} = 4\text{ KB} \)
- 28 层：**每 token 112 KB**

### 9.3 临界点与对比

\[
\text{seq\_len}^* = \frac{528\text{ MB}}{112\text{ KB}} \approx 4700
\]

| 配置             | KV Cache | FFN 权重 |  KV/FFN |
| ---------------- | -------: | -------: | ------: |
| bs=1, seq=1024   |   115 MB |   528 MB |    0.22 |
| bs=1, seq=4096   |   459 MB |   528 MB |    0.87 |
| bs=1, seq=8192   |   918 MB |   528 MB |    1.74 |
| bs=8, seq=4096   |  3.67 GB |   528 MB | **7.0** |
| bs=32, seq=8192  |  29.4 GB |   528 MB |  **56** |
| bs=64, seq=32768 | 234.9 GB |   528 MB | **445** |

**真实部署中 KV Cache 几乎总是远大于单层 FFN 权重**。FFN 权重是一次性预算；KV Cache 随流量线性膨胀——这正是 GQA、MLA、PagedAttention 聚焦压缩 KV Cache 的原因。

## 10. 一次完整前向的数据流

单层 Transformer 块（Qwen3-0.6B）：

```text
输入 x: (bs, seq, 1024)
  ↓
RMSNorm (input_layernorm)
  ↓
```

## 11. 总结

### 各组件一句话概括

| 组件         | 一句话                                                       |
| ------------ | ------------------------------------------------------------ |
| **GQA**      | 多个 Q 头共享 KV 头，KV Cache 按 KV 头数（8）而非 Q 头数（16）存储 |
| **QK-Norm**  | 对每个头的 Q、K 做 RMSNorm（RoPE 之前），防止 softmax 饱和；V 不做 |
| **RMSNorm**  | 只除均方根、不减均值；输出模长恒为 \( \sqrt{d} \)，方向不变  |
| **SwiGLU**   | Swish 门控 × 内容路径，动态调节每个维度通过量；三矩阵、中间 3072 维 |
| **KV Cache** | 按 token 累积的 K/V（8 头 × 128 维），随 batch 与 seq_len 线性增长 |

### 核心数值关系

- \( \text{RMS}^2 = \mu^2 + \sigma^2 \)：均值非零时 RMS > std，RMSNorm 缩放更保守；
- 点积标准差 \( \approx \sqrt{128}\,\sigma^2 \)：不归一化时随 \( \sigma^2 \) 爆炸；
- RMSNorm 后 \( \|q\|_2 = \|k\|_2 = \sqrt{128} \)，缩放后分数硬上界 \( \sqrt{128} \approx 11.31 \)；
- KV Cache 每 token 112 KB，FFN 权重 528 MB，临界 seq_len ≈ 4700（bs=1）。

### 设计动机对照

| 优化目标        | 采用的技术                        |
| --------------- | --------------------------------- |
| 推理显存 / 带宽 | GQA（KV 头减半）、KV Cache 管理   |
| 训练稳定性      | QK-Norm、RMSNorm、Pre-Norm        |
| FFN 表达力      | SwiGLU（乘法门控 + 非饱和激活）   |
| 参数预算平衡    | SwiGLU 中间维度 3072（而非 4096） |
