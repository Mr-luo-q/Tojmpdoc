硬件与系统【已核对】：

```text
型号      Raspberry Pi 4 Model B，8GB

账号      pi / password（弱口令，接入公共网络前建议换掉）

记录      D:\项目\树莓派\树莓派配置记录.md（§12 是网线直连实战）
```

它现在缺两样东西：**bleak**（读蓝牙用）和 **Tailscale**（搬回家之后远程连它用）。两样都要外网才能装。

联网的两条路，按当下场景选：

```text
有外网  开手机热点 smp（烧录时就配进去了，WPA2 / <热点口令已脱敏>）
        Pi 通电 1~2 分钟自己会连上，IP 大概率仍是 192.168.43.33
        已【已核对】验证过：笔记本能 ssh 到它，说明热点允许客户端互访
        代价：手机得一直开着

无热点  网线直连电脑
        【已核对】装备都还在：迷你 DHCP 服务器在跑（PID 48180）、
        计划任务 DSH-Pi-DHCP 是 Ready、以太网上挂着 192.168.137.1
        插线 + 通电 → Pi 拿 192.168.137.50 → 能 ssh
        【已核对】但这条链路只到"能 ssh"：IPv4 转发 Disabled、没有 NetNat，
        电脑不会替它转出去 → apt / pip 会失败
```

今晚的清单：

```text
1  给 Pi 通电（热点或网线二选一），ssh 进去
2  sudo apt update && sudo apt install -y python3-bleak
3  把 _work\ble\scan.py 与 watch.py 传到 Pi 上，先跑一次 scan.py
   目的：确认工具链能扫到周围设备（不需要扫到温湿度计，它在家）
4  装 Tailscale 并登录，确认笔记本能 ssh 到它的 Tailscale 名字
   这一步必须现在做 —— 等 Pi 搬回家，你人在学校就够不到它了
5  （可选）插网线确认直连也能进，作为没有热点时的保底
```
