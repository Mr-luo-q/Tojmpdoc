# 12：三台设备的接入情况与无法连接的原因

> 核对时间：2026-10-15
> 依据：本机实测（HA 沙盒与树莓派两边的接口、米家云设备清单缓存、BLE 扫描与 GATT 连接、
>      Windows 侧 Wi-Fi 扫描）、`_work\05/06/08/11` 号文档、上游官方文档
> 事实分级：【已核对】有可复现证据；【推断】由现象推得；【待确认】需要设备侧或用户确认

## 0 一句话结论

```text
三台设备接不进来的原因各不相同，但都不在 HA 的配置层

氛围灯       已经接进 HA，是灯自己连不上网 —— 它认的是家里的 pearcat，人却在校园网这边
美的温湿度计 完全没接进来，卡在"数据出不来"—— 读数藏在私有协议里，云上也没有数据
涂鸦 Zigbee  完全没接进来，卡在"没有协调器"—— Zigbee 必须有网关或 USB 棒在场，现在没有
```

## 1 现状总表

| 设备 | 通道 | 能不能在 HA 里看到 | 为什么 | 卡在哪一层 |
| --- | --- | --- | --- | --- |
| 米家对开门冰箱 | 米家云（`xiaomi_home`） | 实体常年可用 | 云端在线 | 无（对照组） |
| 蓝牙音箱 ERAZER SAB6 | 本机 MQTT 桥（`bt_speaker`） | 桥在跑就可控 | 蓝牙经典，本机直连 | 桥进程要起 |
| **氛围灯** | 米家云（`xiaomi_home`） | 40 个实体，全部 `unavailable` | 设备云端离线 | 设备侧网络 |
| **美的温湿度计** | 米家云 / 蓝牙 | 只有 1 个 `unavailable` 的状态实体 | 读数没出来 | 协议 + 网关 |
| **涂鸦 Zigbee 温湿度传感器 ×4** | Zigbee | 完全没有 | 没有协调器 | 缺硬件 |

这张表的规律只有一条：

```text
走云的设备    只要设备在云端在线，HA 就能随时看、随时控（冰箱、氛围灯都属这一类）
走本地的设备  需要一个常驻进程或常驻硬件待命（蓝牙音箱的桥、Zigbee 的协调器）
```

## 2 氛围灯：接进来了，但灯自己没网

### 2.1 已经接好的一侧（HA）

```text
接入方式   米家云 → 官方 xiaomi_home 集成（走了一次 options flow 刷新设备清单）
设备身份   did 2109161199 / 型号 hzsj.light.wyra02 / 名字"山晶特控 氛围灯WiFi版" / 房间 A320
urn        urn:miot-spec-v2:device:light:0000A001:hzsj-wyra02:1
导入实体   40 个：灯本体 + 3 个 switch + 7 个 number + 3 个 select + 6 个 sensor + 12 个 button
灯本体     light.hzsj_cn_2109161199_wyra02_s_2_light，支持 亮度 / 色温 / RGB
MCP 侧     已认领为 cn_2109161199，动作面 turn_on / turn_off / toggle /
           set_mode(上电开/上电关/上电保持) / set_percentage(0-100)
```

这一侧没有遗留问题：设备在、实体在、动作规格在。

### 2.2 接不上的一侧（设备）

```text
【已核对】米家云缓存里这台灯的 online = false
          ssid = pearcat（它记住的那张网）  rssi = -44（最后一次在线时的快照）  local_ip 为空
【已核对】当前位置能扫到的 Wi-Fi 只有 tjuwlan，没有 pearcat，也没有它的配网热点
          （热点 hzsj-light-wyra02_mibtF3E6 没出现，说明它没进配网模式，只是在反复重试旧网络）
【已核对】用 MCP 发过一次 execute_action(cn_2109161199, turn_on)，返回
          error.code = DEVICE_UNAVAILABLE
```

整条链断在"灯 → 互联网"这一段：HA、米家云、实体、动作全都在等它上线。
校园网这条路本身也不通 —— tjuwlan 是网页认证型网络，物联网设备没有浏览器，连上也过不了认证。

### 2.3 让它变成"随时可看可控"的三条路

```text
一  把灯放回 pearcat 覆盖的地方（家里）→ 插电自动上线，什么都不用再配。
    上线后 40 个实体自动从 unavailable 变实时可用，和冰箱完全同款体验。
二  想在这边用它 → 先给它一张它能连的网：手机热点，或宿舍自己的路由器；
    然后用米家 App 重新配一次网（需要手机 + 灯上的配网键，无法远程代做）。
    代价：手机热点得常开，灯才有网。
三  先不用它 → 沙盒里那 25 个虚拟设备可写可读，足以验证"MCP 能不能控制"这条链。
```

**待确认**：灯到底在不在 pearcat 覆盖范围内 —— 如果它其实在家里、只是断电或掉线，
那就属于第一种情况。判断方法很简单：它通电且网络可达时，云端的 `online` 会自己变 true。

## 3 美的温湿度计：读数出不来

### 3.1 身份

```text
云端 id   212305752896363     类型 T0x54 / subtype 1001 / sn8 402M0001
蓝牙      地址 50:5E:3A:E9:93:2C   广播名 'midea'
          Device Information 服务实测：厂商 "midea" / 型号 "MHS-AC-02" /
          硬件 "ST249CA1" / 固件 "V1.0.9"
```

### 3.2 两条通道各自的实测结论

```text
云通道（美的云 / 米家）
  已核对  美的美居里显示"数据未同步，要连蓝牙或网关"，也就是设备数据根本没上云
  已核对  上游 midea_auto_cloud 集成缺 T0x54 的映射文件，该条目当前处于停用状态

蓝牙通道（Windows 与树莓派两边实测）
  已核对  广播 180 秒共 936 包，去重后只有两种载荷，一个字节都不变：
          一种带它自己的 MAC 反序，一种是 ASCII "402M0001549004"（与 sn8 对得上）
          → 广播里只有身份，没有温湿度读数，也没有 0x181a 环境感知服务
  已核对  主动连接能建立（不需要配对密钥），但 6 个厂商特征直接读全是 0x00；
          订阅 3 个 indicate 特征后 90 秒零通知，随后连接被设备主动断开
  已核对  公开资料零命中：GitHub 搜 MHS-AC-02 / ST249CA1 / midea bluetooth ff80 都是 0 个仓库
```

结论：读数走它自己的私有协议（写命令 + 收通知），而且它只肯跟自家 App 说话。

### 3.3 三条出路

```text
① 买美的网关      按 App 的提示加一个网关，让设备上云；之后启用 midea_auto_cloud 条目即可读
② 换设备          米家蓝牙温湿度计2 / 青萍 CGDK2 这类 HA 自带译码的 BLE 传感器，
                  树莓派的蓝牙已经验证就绪，零开发，当天可接
③ 逆向协议        抓手机 App 的蓝牙链路日志反推握手与命令格式。
                  成本数天量级，且固件一改就可能失效，不建议作为主线
```

## 4 涂鸦 Zigbee 温湿度传感器：缺硬件

### 4.1 设备是什么

```text
来源      用户提供的说明书：涂鸦系白牌，经销商"黄石惠乐网络科技有限公司"
协议      Zigbee 3.0       供电 2 节 7 号电池       量程 -10~55℃，0~99%RH
说明书写明 "此款式需要涂鸦 zigbee 网关协作使用"
```

说明书那句话只对"用涂鸦 App"那条路成立。涂鸦的 Zigbee 传感器本身是标准 Zigbee 3.0 设备，
用自己的协调器可以绕过涂鸦网关，代价是它不再出现在涂鸦 App 里、数据也不上涂鸦云。

### 4.2 为什么接不进来

```text
【已核对】本机没有任何 Zigbee 硬件：设备管理器里只有蓝牙虚拟串口 COM3~COM6，没有
          CH340 / CP210x / FTDI 之类的 USB 桥；树莓派上也没有 /dev/ttyUSB* 与 /dev/serial
【已核对】HA 官方 ZHA 文档明确：协调器通过串口代理走 Wi-Fi / WAN / VPN 是 not recommended
          → "棒插在笔记本上、让家里的设备连过来"这条路被官方否掉
```

### 4.3 两条可选路线（都要买一件硬件）

```text
A 自建协调器 + ZHA     80~200 元   棒插在家里那台跑 HA 的机器上（树莓派），本地、无云
  已核对：ZHA 官方 quirk 库里有专门的 TS0201 补丁；Zigbee2MQTT 有 TS0201 设备页
B 涂鸦 Zigbee 网关     40~70 元    挂涂鸦云，再用官方 tuya 集成扫码授权导入；跨网络可用
```

树莓派侧的准备已经做完（2026-10-14 实测）：`modemmanager` 未安装（官方点名的抢串口问题不存在）、
bleak 0.11.0 已装、HA 容器里 `zha` 组件在、扫描工具可跑。棒一到，只剩"按配置键配网"这一个动作。

## 5 三个设备的最小待办

```text
氛围灯        确认它所在的网络：在家里（pearcat）插电即可；在这边就要重新配网到热点或路由器
美的温湿度计  决定买美的网关，还是换一台米家 / 青萍的 BLE 传感器
涂鸦 Zigbee   买一根协调器（推荐，插树莓派）或一个涂鸦网关，然后装电池配网
```
